## Install

1. Flash in KernelSU Manager
2. Reboot
3. Tap **Action** button to run fix
4. Reboot again

## Action flow

- Before Action: **❌ Detection Fail**
- Tap Action: Premium Root Hide UI + 8 sec timer
- After: **✅ Detection Fixed** + Developed By @Hivirtus
